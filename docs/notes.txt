* By design, some indicators or their features will not appear until they meet certain criteria
========================================================================
        - indicator-messages    # Won't appear until a messaging type application is run first (e.g. evolution, mailnag (via mailnag-messagingmenu-plugin), pidgin)
        - indicator-keyboard    # Won't appear until at least one input source is specified and 'Show current input source in the menu bar' is checked in System Settings > Text Entry
        - indicator-session     # Won't show the user name until 'Show my login name in the menu bar' is checked in System Settings > User Accounts
                                        the full name (GECOS field) is shown if set, otherwise the login name

========================================================================
* Debugging Unity
========================================================================
        - Emerge unity-base/unity with the 'debug' USE flag enabled, then log out and back in
        - Check 'journalctl --user -b' (e.g. 'journalctl --user -u unity7.service') and ~/.xsession-errors
        - gsettings get org.compiz.core:/org/compiz/profiles/unity/plugins/core/ active-plugins

========================================================================
* Debugging top panel systray/indicator icons and menus
========================================================================
        - In desktop user's xterm, issue the following command:
                killall indicator-application-service; G_MESSAGES_DEBUG=all /usr/libexec/indicator-application/indicator-application-service
        - Get list of currently running indicators with the following command:
                dbus-send --type=method_call --print-reply --dest=com.canonical.indicator.application \
                        /com/canonical/indicator/application/service com.canonical.indicator.application.service.GetApplications

========================================================================
* Systemd session launch
========================================================================
* Unity session is launched as follows:
        - Display manager (e.g. LightDM) executes /usr/share/xsessions/unity.desktop:
                - '/usr/share/xsessions/unity.desktop' executes '/usr/bin/unity-session'
                - '/usr/bin/unity-session' executes '/usr/libexec/run-systemd-session unity-session.target'
                        OR
        - Started from console with 'XSESSION=unity startx':
                - '/etc/X11/xinit/xinitrc.d/99unity-session_systemd' sets XDG_CURRENT_DESKTOP="Unity:Unity7",
                  passes the environment to the 'systemd --user' process and executes '/usr/bin/unity-session'

                - '/usr/libexec/run-systemd-session unity-session.target' runs 'systemctl --user start --wait unity-session.target'
                - '/usr/lib/systemd/user/unity-session.target' starts:
                        - 'unity-session.service' which in turn executes 'cinnamon-session --session=unity'
                        - 'unity7.service' due to existence of '/usr/lib/systemd/user/unity-session.target.requires/unity7.service' symlink
                        - 'unity-settings-daemon.service' and 'window-stack-bridge.service' due to existence of symlinks
                          in '/usr/lib/systemd/user/unity-session.target.wants/'
                - All other Unity systemd service units are then started as being 'PartOf=graphical-session.target'
                - Most importantly, unity7.service unit does the following:
                        - Executes '/usr/lib64/unity/systemd-prestart-check' to check if Compiz is not already started
                          by cinnamon-session or if we're in an Upstart session
                        - Sets the compizconfig profile to 'COMPIZ_CONFIG_PROFILE=ubuntu' and the Unity settings profile
                          to 'UNITY_DEFAULT_PROFILE=unity' (or 'unity-lowgfx') via '/usr/lib64/unity/compiz-profile-selector'
                        - Performs 'ExecStart=/usr/bin/compiz'
                        - Wants {unity-settings-daemon,unity-panel-service,bamfdaemon}.service units

========================================================================
* OpenRC session launch (experimental)
========================================================================
* Unity session is launched as follows:
        - Display manager (e.g. LightDM) sources '/etc/X11/xinit/xinitrc.d/*' and executes /usr/share/xsessions/unity.desktop:
                - '/etc/X11/xinit/xinitrc.d/80-dbus' launches the session bus via 'dbus-launch'
                  (the ehooks condition skips it only when systemd is running)
                - '/etc/X11/xinit/xinitrc.d/99unity-session_systemd' passes the environment to D-Bus activated services
                - '/usr/share/xsessions/unity.desktop' executes '/usr/bin/unity-session'
                        OR
        - Started from console with 'XSESSION=unity startx':
                - '/etc/X11/xinit/xinitrc.d/99unity-session_systemd' sets XDG_CURRENT_DESKTOP="Unity:Unity7"
                  and executes '/usr/bin/unity-session'

                - '/usr/bin/unity-session' executes 'cinnamon-session --session=unity'
                  (wrapped in 'dbus-run-session' if no session bus is available)
                - cinnamon-session starts the required component and the XDG autostart files (OnlyShowIn=Unity):
                        - 'unity-settings-daemon.desktop' (phase Initialization)
                        - 'unity7-compiz.desktop' (phase WindowManager) executes '/usr/libexec/unity7-compiz-launcher',
                          which sources '/usr/lib64/unity/compiz-profile-selector' and executes 'compiz'
                        - 'unity-panel-service.desktop' (phase Application, as it doesn't register with the session manager)
                          executes '/usr/lib64/unity/unity-panel-service'
                        - 'window-stack-bridge.desktop', 'indicator-application.desktop', 'indicator-messages.desktop'
                          and 'indicator-printers.desktop'
                - Other indicator services are started via D-Bus activation ('/usr/share/dbus-1/services/com.canonical.indicator.*.service')
                  when unity-panel-service (or unity-greeter) loads the indicators
                - On screen lock, Unity launches '/usr/lib64/unity/unity-panel-service --lockscreen-mode' directly
                  instead of starting 'unity-screen-locked.target'
                - indicator-datetime reads the system timezone from org.freedesktop.timedate1 provided by app-admin/openrc-settingsd

* Compiz performance settings for 'ccsm'
========================================================================
 Click on "OpenGL" and set "Texture Filter" to "Fast".
 Make sure "Sync To VBlank" is selected, that "Texture Compression" is NOT selected, and make sure "Framebuffer object",
 "Vertex buffer object" and "Always use buffer swapping" ARE all selected.
 Scroll down to "Image Loading" and make sure all plugins ("JPEG", "PNG", "SVG" and "Text") ARE selected.
 * Some applications such as Steam or Chromium with hardware acceleration enabled may lose window focus, particularly
   after unminimising the window or waking from screen lock/blank
        - Enabling the "Keep previews of minimized windows" option under "Workarounds" fixes this issue
